> **Turn the things you want to do into points, and the things you want to enjoy into rewards.**

**LifePoints** is a lightweight, offline-first personal points and self-management app.

You can assign points to activities such as studying, working, exercising, or reading, and get immediate feedback when you complete them. You can also turn games, movies, snacks, shopping, and other things you enjoy into rewards that can be redeemed with the points you have earned.

There is no complicated task system and no need to build a huge planning framework. The core idea is simple:

**Do something → Earn points → Spend points on something you enjoy.**

## Features

### Tasks

Tasks is the default home screen of LifePoints and the page you will probably use most often.

You can create reusable activities such as:

- Study for 10 minutes
- Read 10 pages
- Finish a work task
- Exercise for 20 minutes
- Tidy the room

Each Task can have its own point value. Tap the points and they are immediately added to your balance and Timeline.

Features include:

- Reusable Tasks
- Custom names and point values
- Tap the name to edit directly
- Custom icons
- Custom frequently used icon library
- Second confirmation before deletion
- Real-time current balance
- Total earned points display

#### Multipliers

LifePoints supports point multipliers.

For example, for the same task, “Study for 10 minutes”:

- Normal situation: `1×`
- You clearly do not feel like studying but still choose to start: `2×`
- You complete it under especially difficult circumstances: `3×`

The multiplier can be switched directly in the Task row and can also be customized in Settings.

The purpose is not to make things more complicated, but to let you adjust the reward feedback according to how difficult the task actually feels at that moment.

---

### Rewards

Rewards are used to spend the points you have earned.

For example:

- Play a game for 10 minutes
- Watch one episode of a show
- Watch a movie
- Eat a favorite snack
- Buy a small item you want

Each Reward can have its own point cost.

Features include:

- Reusable Rewards
- Custom names and point values
- Tap the name to edit directly
- Custom icons
- Custom reward icon library
- Optional confirmation before spending points
- Second confirmation before deletion

LifePoints does not try to stop you from having fun. It simply makes the feedback relationship between “getting things done” and “enjoying rewards” clearer.

---

### Timeline

Timeline is the point transaction history in LifePoints.

Every time you earn or spend points, it records:

- Time
- Item name
- Points earned or spent

At the top of the page, you can see:

- **Gained**: points earned
- **Spent**: points spent
- **Net**: net change

#### Undo accidental actions

If you accidentally tap a Task or Reward, you can undo it directly from Timeline.

- Undo earned points: the corresponding points are deducted from your balance, and Total earned is corrected as well
- Undo spent points: the corresponding points are returned to your balance
- The corresponding Timeline entry is deleted at the same time

This means you do not need to manually rebalance your points by making a fake transaction.

### Settings

LifePoints includes a number of simple but useful personalization options:

- **Light** mode
- **Pure Black** mode
- Four font sizes: Small / Default / Large / XL
- Custom point multipliers
- Custom Task icon library
- Custom Reward icon library
- Confirmation before spending points
- Haptic feedback that follows Android system settings
- JSON data export
- One-tap clear all data
- Support me
- Check for updates

## In-app updates

Go to:

**Settings → Check for updates**

LifePoints checks the latest version available in GitHub Releases.

If a new version is available, you can download and install it directly, and Android will perform an in-place update.

On Android 8.0 and later, the first in-app update may require you to allow LifePoints to install unknown apps. Once authorized, future updates are much more convenient.

## Data and privacy

LifePoints currently follows an **offline-first** design.

- No account registration required
- No login required
- No cloud server required
- No ads
- Tasks, Rewards, Timeline, balance, and settings are stored locally on your device
- Personal usage data is not uploaded by default
- JSON data can be exported manually for backup

Even without an internet connection, the main features continue to work normally except for checking updates and opening GitHub pages.

## Why I made LifePoints

For many things, the problem is not that we do not know what we should do. The problem is that long-term benefits feel too far away while short-term feedback is too weak.

Studying, exercising, and working may take a long time before they produce visible results, while games, videos, snacks, and other forms of entertainment often provide immediate feedback.

LifePoints tries to do one simple thing:

**Add immediate feedback to behaviors that are valuable in the long run.**

Finish something and get points immediately. Accumulate those points, then spend them on rewards you genuinely want.

It is not meant to create a strict reward-and-punishment system, nor is it meant to quantify every part of your life. You can record only the things that are useful to you, and you can adjust points, multipliers, and rewards at any time.

LifePoints is better thought of as a simple personal feedback tool.
